Koha 25.05.16 is a bugfix/maintenance and security release.

It includes 8 bugfixes.

System requirements

You can learn about the system components (like OS and database) needed for running Koha on the community wiki.

Security bugs

  • 42946 [CVE-2026-16031] Time-based Blind SQL Injection in itemsearch.pl functionality
  • 43429 Stored XSS via OPAC Report a Problem executes in staff/intranet security context (8.7 HIGH)
  • 43634 cancelBulk in waitingreserves.pl is not protected against CSRF attacks
  • 43707 Fix stored XSS in DT's column filters in staff interface

Bugfixes

Circulation

Other bugs fixed

  • 41451 Hold history search fails when itemtype column present

    This fixes filtering on a patron's holds history when AllowHoldItemTypeSelection is enabled. This previously produced a 500 error when searching, but now works as expected.

Installation and upgrade (command-line installer)

Critical bugs fixed

  • 42886 CSS files not installed

Other bugs fixed

  • 42850 ILL requests stylesheet is not installed

System Administration

Other bugs fixed

  • 43336 Remove support for LibrisSpellcheck

    This removes support for LibrisSpellcheck, as the API that this feature was based on was removed by the Swedish National Library.

    It removes two system preferences: LibrisKey and LibrisURL. It also removes the LibrisSpellcheck option from "Did you mean?" (Administration > Additional parameters > Did you mean?).

Deleted system preferences

  • LibrisKey
  • LibrisURL
